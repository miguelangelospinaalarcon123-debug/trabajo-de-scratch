# Sistema de Inicio de Sesión

## Descripción

Este proyecto consiste en una simulación de un sistema de registro e inicio de sesión desarrollado en **Scratch 3.0**. Permite registrar un usuario con su correo electrónico y contraseña, y posteriormente validar esta información para acceder al sistema.

## Funcionalidades

* Registro de usuario.
* Registro de correo electrónico.
* Registro de contraseña.
* Inicio de sesión.
* Validación del correo electrónico y la contraseña.
* Mensajes de error cuando los datos ingresados son incorrectos.

## Objetivo

Diseñar un sistema básico de autenticación que permita comprender el funcionamiento del registro de usuarios y la validación de credenciales mediante el uso de la lógica de programación.

## Herramienta utilizada

* Scratch 3.0

## Cómo ejecutar el proyecto

1. Descargar el archivo **.sb3**.
2. Abrir el archivo en Scratch 3.0.
3. Hacer clic en la bandera verde para iniciar el programa.
4. Registrar un usuario con su correo y contraseña.
5. Iniciar sesión utilizando los datos registrados.
